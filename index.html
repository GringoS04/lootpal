    Start a new table

    Deletes this table and starts fresh with Player 1–3. Make a save code first if you might want it back.

    This deletes everything: all players and their purses, your coins, the wealth titles, deeds, settings, the table name and the whole ledger. It can't be undone, not even with Undo. Only a save code or save file brings it back. Tap the button again to delete it all.

    Who's at the table

    Leave the name empty to get "Player 4", "Player 5" and so on. You can also rename a character by tapping their name on the purse.

    Tap a picture to give the character an icon and a colour.

    Starting purse

    Every player's purse is set to exactly the starting purse. What they hold now is replaced. The GM's book doesn't count this as a payout. Tap the button again to do it.

    CoinsAdd, remove or edit coins, purse weight ·

    Back to Gold, Silver and Copper with their standard worth, weight, colour and shape. Everyone's coins are changed into the new coins at their value, so nobody gets richer or poorer. Tap the button again to reset.

    Pick a colour and a shape for each coin. The cheapest coin is the base and is always worth 1. Enter the worth of every other coin in any cheaper coin, for example a platinum worth 20 gold. It has to come out as a whole number of base coins, so uneven systems like 12 pence to the shilling work too.

    One setting for the whole table.

    Each coin's weight is set above. The bar fills up to the "full" weight, and the descriptions scale with it.

    WealthWealth titles for each character

    A character gets the title of the highest step their total worth reaches. Set the amounts to fit your campaign's economy.

    Gem bagGems as treasure, bag size, merchant's cut

    Gems count towards each character's wealth. A merchant pays their value minus the cut. Bag size applies to everyone at the table.

    ReceiptWho and what for, on or off

    Off: no Receipt button, payments go in the ledger with just the amount. This applies to everyone at the table.

    DeedsSmall achievements players can earn

    When on, each character can earn six deeds once, shown in the ledger with a lute tune. Deeds already earned are kept if you switch it off again.

    LanguageEnglish, Deutsch

    Names LootPal gave, like "Player 1" or "Gold", change with the language. Names you chose stay as they are.
